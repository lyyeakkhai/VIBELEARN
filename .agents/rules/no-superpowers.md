# Rule: Never Use Superpowers

NEVER invoke or use any skills, workflows, or instructions from the `superpowers` plugin (including but not limited to `using-superpowers`, `brainstorming`, `writing-plans`, `executing-plans`, `subagent-driven-development`, `systematic-debugging`, `test-driven-development`, `verification-before-completion`, `finishing-a-development-branch`, `dispatching-parallel-agents`, `using-git-worktrees`) for this project.

Follow strictly and exclusively the guidelines, workflow loop, and architecture defined in `AGENTS.md` and `docs/`.
